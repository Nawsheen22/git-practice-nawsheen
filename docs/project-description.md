# Project Description

A simple Python project used to practice Git commands: init, add, commit, branch, merge and push.

## Features

- `src/main.py` prints my name and today's date, then runs calculator examples.
- `src/utils.py` contains calculator functions: `add`, `subtract` and `multiply`.

## Git Workflow Used

1. Made the initial commit on `main`.
2. Added the calculator on the `feature/calculator` branch and merged it into `main`.
3. Pushed the project to GitHub.
4. Added error handling on the `feature/error-handling` branch and merged it into `main`.
